# ReviewCraft Chrome Extension — Google Review Auto-Filler

આ Chrome Extension ની મદદથી જ્યારે પણ તમે ReviewCraft માંથી **Open Google** ક્લિક કરશો, ત્યારે:
1. Google નું Review Dialog તરત ખુલશે.
2. સિલેક્ટ થયેલું **Review Text આપમેળે Google ના ટેક્સ્ટબોક્સમાં ટાઇપ થઈ જશે**.
3. કાર્ડ પર જેટલા સ્ટાર હતા (દા.ત. **5-Star અથવા 4-Star**) તે **સ્ટાર પણ આપમેળે સિલેક્ટ (Click) થઈ જશે**!

---

## Chrome માં Extension કેવી રીતે ઇન્સ્ટોલ કરવું (How to Install):

ફક્ત ૧૦ સેકન્ડમાં આ Extension તમારા Google Chrome બ્રાઉઝરમાં ચાલુ થઈ જશે:

1. **Google Chrome બ્રાઉઝર ખોલો** અને URL બારમાં આ ટાઇપ કરી Enter આપો:
   ```text
   chrome://extensions/
   ```

2. ઉપર જમણી બાજુ (Top Right) રહેલું **"Developer mode"** નું બટન **ON** (ચાલુ) કરો.

3. ઉપર ડાબી બાજુ દેખાતા **"Load unpacked"** બટન પર ક્લિક કરો.

4. ફાઈલ સિલેક્ટર ખુલશે, તેમાં નીચે આપેલ ફોલ્ડર સિલેક્ટ કરો:
   ```text
   [તમારું પ્રોજેક્ટ ફોલ્ડર]\Google-review-system-main\extension
   દા.ત. C:\Users\dhrum\OneDrive\Desktop\Review _predection_system\Google-review-system-main\extension
   ```
   અને **"Select Folder"** બટન દબાવો.

5. બસ! **ReviewCraft Google Review Auto-Filler** એક્સટેન્શન તમારા Chrome માં એક્ટિવ થઈ જશે! 🚀

---

## કેવી રીતે વાપરવું (How to Use):

1. તમારા ReviewCraft ડેશબોર્ડ (`http://localhost:5173`) પર જાઓ.
2. ગમતા Review Card પરનું **"Open Google"** બટન ક્લિક કરો.
3. Google નું પેજ ખુલતાં જ એક્સટેન્શન આપમેળે:
   - લખાણ પેસ્ટ કરી દેશે.
   - સ્ટાર્સ સિલેક્ટ કરી દેશે.
   - નીચે એક લીલું નોટિફિકેશન દેખાશે: *"ReviewCraft Auto-Filled: Review text & Stars populated!"*
4. તમારે ફક્ત છેલ્લે **Post** બટન દબાવવાનું રહેશે!
